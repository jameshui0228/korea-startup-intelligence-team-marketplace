# 초기 신호 → 한국 사업기회

## 수집과 사실 확인은 서로 다른 순서

탐색 우선순위는 사용자 요구에 따라 T1(신규 제품·GitHub·특허·채용·크라우드펀딩·개발자 커뮤니티),
T2(검색·소비 행동), T3(SNS·일반 커뮤니티), T4(언론·보고서·대기업 발표)다.
그러나 T1이 더 진실하다는 뜻은 아니다. 사실 확인에는 원자료·정부·기업 공식 문서와 독립 반증을 우선한다.
GitHub 새 프로젝트·별은 기술 공급 신호, 투자 발표는 자금 공급 신호다. 소비 수요를 따로 찾아야 한다.

수집 CLI의 제목·링크만으로 인사이트를 확정하지 않는다. 관심 후보 3~5개만 원문을 실제로 열어 확인하고,
상위 후보마다 가능하면 2~3개 서로 다른 자료 계열과 원래 생산자를 추적한다.
Google News와 Naver가 동일 보도자료를 제공한 경우 한 근거다. 원문 다른 언론이라도 같은 인용이면 독립성이 아니다.

## 시간과 성장 측정

- 관측값과 관측 구간, 지역, 단위, 분모, 쿼리, 표본 필터, 수집 시각을 함께 남긴다.
- 네이버 검색 트렌드: 동일 84일 요청 안에서 일자별 상대 지수를 비교한다. 지난 7일 대 직전 7일과 가속도를 기술한다.
  28일 연속 데이터·완료된 날짜·최근 종료일이 없거나 낮은 기저면 판단을 보류한다. 30% 변화 기준은 초기 검토용 휴리스틱이다.
  통계적 유의성, 1년 계절성 조정, 예측 검증을 했다고 말하지 않는다. 별도 요청의 0~100을 접합하지 않는다.
- Google Trending Now의 traffic bucket은 전체 키워드의 추세가 아니다. 일회성 사건/인명/스포츠 결과를 구분한다.
- GitHub 현재 stars, HN points, YouTube 검색 결과 수를 성장률로 변환하지 않는다.
  반복 스냅샷과 동일 모집단/기간을 확보했을 때만 변화율을 계산한다. 새로 생성된 프로젝트 편향·봇을 확인한다.
- 광고 집행, 캠페인, 명절·개학·스포츠 시즌, 정책 발표, 일시적 품절, 데이터 수집 변경을 대안 설명으로 적는다.
- 음의 변화도 보존한다. 쇠퇴와 그로 인한 새로운 고객 문제는 다른 판단이다.

## 단계와 신뢰도

최신 추가 요청의 단계 체계: Weak Signal → Emerging → Accelerating → Mainstream → Saturated.
이전 원문 Growing은 Accelerating의 전 단계/동의적 메모로만 보존하고 신뢰도 숫자로 사용하지 않는다.

| 단계 | 필요한 확인 |
|---|---|
| Weak Signal | 날짜와 출처가 있는 초기 현상; 반복성/수요는 미검증 |
| Emerging | 독립 출처 계열에서 반복; 확산이 시작된 근거; 원천 중복/광고 여부 검토 |
| Accelerating | 비교 가능한 반복 시계열에서 성장/가속; 별도 행동 자료; 계절성·기저 확인 |
| Mainstream | 실제 한국 채택/사용 규모·유통 접근성·대중화의 근거 |
| Saturated | 실제 경쟁 구조·획득 비용·공급 과잉/가격 압력; 단순 유명함만으로 판정하지 않음 |

자동 엔진의 `Emerging_candidate`는 **검토 후보**다. `stage=unreviewed`를 사람/에이전트 원문 검토 없이 확정 단계로 바꾸지 않는다.
근거 신뢰도는 별도 제한적/중간/높음과 그 이유로 표시한다. 자료가 부족하면 Unknown을 허용한다.

## 점수

Trend Score 가중치는 성장 25, 플랫폼 동시성 15, 새로움 10, 글로벌 확산 10, 한국 적용 15,
문제 강도 10, 사업화 10, 낮은 경쟁 5다. 각 항목에 관측 근거·스케일 정의·평가자를 남긴 경우에만
가중 합을 계산한다. 하나라도 미확인이면 전체 점수를 비워 두고 High/Medium/Low/Unknown과 이유를 쓴다.
점수는 우선순위 판단이지 성공확률이 아니다. 한국 기회도 문화·유통·규제·지불자·MVP·대기업 진입을 따로 판단한다.

## Korea Gap 검증

미국만 보지 않고 일본/중국/유럽/인도/동남아 등에서 관련성을 골라 조사한다. 검색 범위와 언어를 기록한다.
국내 검색에서 결과가 없다는 이유만으로 “한국에는 없다”고 하지 않는다. 한국어 유사어·업계용어·대체재·기업 고객용 비공개 제품을 확인한다.
관찰된 해외 성장 → 한국 유통/가격/규제/노동 비용/사용행태 차이 → 어떤 현지화가 필요한지를 연결한다.
3개월~3년 전망은 기간별 가설로 작성한다. 검증된 확률이 없으면 임의 확률을 붙이지 않는다.
