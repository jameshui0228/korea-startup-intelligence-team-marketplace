# 전 분야 아이디어와 검증

## 발산

400개 분류는 탐색 지도이며 완결된 산업 분류나 숙련도 증명이 아니다. 원본의 겹치는 분야를 임의 삭제하지 않는다.
요청 분야가 없으면 `ideation-plan`에서 미조회 분야를 확인한다. 소프트웨어·서울·20대 소비자에만 집중하지 않는다.
10개를 요청하면 가능한 한 5개 이상의 서로 다른 분야와 B2B/B2C/B2G, 오프라인/서비스/하드웨어를 섞되
개수를 맞추려고 없는 근거를 만들지 않는다. 근거 있는 기회와 탐색용 가설을 분리한다.

산업 × 특정 사용자 × 특정 순간 × 반복 불편을 기본 단위로 삼는다.
기술 가격 하락, 정보 비대칭, 신뢰, 반복 수작업, 거래 마찰, 한국 현지화, 산업 간 성공 모델 이전을 조합한다.
단순 “AI 앱/플랫폼” 대신 누가 언제 어떤 기존 작업을 어떻게 바꾸고 누가 어떤 단위로 지불할지 써야 한다.
새 분야는 기존 taxonomy와 연결 가능한 확장 제안으로 남긴다. 사용자 원본 분류는 자동으로 변경하지 않는다.

## Pain mining

“엑셀로 관리”, “매번 직접”, “한국에서는 못 쓴다”, “돈 내고라도” 등은 문제 탐색 단서다.
한 사람의 여러 게시물과 복제된 리뷰를 반복 수요로 세지 않는다. 공개 글의 맥락, 현재 대안, 빈도,
얼마를 이미 지출하는지를 검토하고 식별정보·민감정보를 저장하지 않는다. 고객을 사칭한 합성 인터뷰는 증거가 아니다.

## 수렴과 반증

모든 후보에 다음을 확인한다.

1. 구체 고객·문제·빈도·심각도·현재 해결 비용.
2. 직접 경쟁·간접 경쟁·수작업/엑셀/카카오톡·오프라인 대안; 왜 바꿀지.
3. 지불자와 사용자 차이, 구매 권한·예산·도입 절차·반복 사용 가능성.
4. 한국형 유통·모바일·플랫폼 의존·지역 차이·가격 적합성. 국가 특성을 고정관념으로 추정하지 않는다.
5. 시장 규모는 bottom-up 단위×검증된 수량×가격부터. 출처·기간·추정 범위·민감도를 명시하고 최신 공식 통계를 확인한다.
6. CAC/LTV/객단가/마진/거래액과 매출의 정의, 기간, 단위를 분리한다. 거래 경험 없는 수치는 가설이다.
7. 고객 접근 경로와 최초 10명의 구체 모집 방식. 연락이나 광고 집행은 사용자가 요청하기 전 수행하지 않는다.
8. 진입장벽·특허/브랜드/데이터 권리·의료/금융/개인정보/아동/안전 규제. 실제 사업 형태와 현행 한국 법에 맞춰 확인한다.
9. MVP는 가장 위험한 한 가설을 최저 비용으로 검증하도록 설계한다. 개발부터 제안하지 않는다.
10. 가설별 통과/중단 기준·기한·관측 방법·비용·반례를 먼저 정한다.

기존 dossier를 개선할 때 [창업자·대안 검토](venture-review.md)를 읽고 실제 고객 질문과 현상 유지 포함 대안을 비교한다.
실행 가능한 실험을 정했다면 [사전 실험과 결과](validation.md)의 전용 명령으로 계획과 결과를 분리한다.

문제가 약하면 칭찬 대신 약한 이유를 설명하고 타깃/문제/수익 모델을 바꾼 대안을 제안한다.
기술적으로 단순하다는 이유만으로 제외하지 않는다. 실제 고객 가치·유통·운영 우위가 있으면 검토한다.

## 단계별 실행

문제 발견 → 실제 고객 인터뷰 → 대안/가격/시장 조사 → 수동 실험/랜딩페이지 → 제한된 MVP →
활성/반복 사용/결제 → 채널·단위경제 검증 → 운영/팀/투자.
각 단계의 미확인 가설에 맞춰 1~2개의 작업만 활성화한다. 책의 프레임워크나 GitHub 성공 주장은 실험 결과가 아니다.

## 카드 필드

idea, problem, target, solution, market, competitors, business_model, differentiation, domain_ids,
evidence_ids, assumptions, validation, score(기본 null), risk, next_experiment, status, last_updated.
실제 기록은 `record idea --file ...`; 최소 요구 필드는 CLI 도움말과 learning 참조의 예시를 따른다.
가설을 제안한 후 다음 행동은 바로 검증 가능한 한 가지를 택한다. 지원금을 받을 법한 말보다 실제 수요를 먼저 본다.
