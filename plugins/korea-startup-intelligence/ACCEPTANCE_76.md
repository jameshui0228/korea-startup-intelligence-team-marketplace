# 76개 개선 항목 수용·검증표 (v0.5.0)

이 표는 2026-09-18 사용자 감사 목록의 **1~76번 전부**를 추적한다. `구현`은 호출 가능한 코드와 로컬 검증 경로가 있다는 뜻이며 성능/사업 성공을 뜻하지 않는다. `부분`은 동작하는 좁은 경로가 있지만 정확도·자동화 범위가 부족하다. `연결 대기`는 공개 웹 원문/허용 export의 검토·접수는 가능하지만 해당 플랫폼 직접 API가 없다. `실측 대기`는 산식/분모가 있으나 실제 결과 표본이 부족하다. `설정 대기`는 앱 예약 등록과 실제 회차 영수증이 필요하다. 상세 코드는 `scripts/ksi_lib/`, 명령 진입점은 `scripts/ksi.py`, 회귀 검사는 `tests/`에 있다.
