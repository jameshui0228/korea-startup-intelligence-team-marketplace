# 76개 개선 항목 수용·검증표 (v0.6.1)

이 표는 2026-09-18 사용자 감사 목록의 **1~76번 전부**를 추적한다. `구현`은 호출 가능한 코드와 로컬 검증 경로가 있다는 뜻이며 성능/사업 성공을 뜻하지 않는다. `부분`은 동작하는 좁은 경로가 있지만 정확도 범위가 부족하다. `무키 구현`은 직접 플랫폼 API 대신 사용자가 호출한 현재 작업에서 공개 웹 계획→원문 검토→원자적 일괄 접수 경로가 있다는 뜻이며 전수조사나 실시간 피드를 뜻하지 않는다. `실측 대기`는 산식/분모가 있으나 실제 결과 표본이 부족하다. `범위 제외`는 사용자 결정으로 제품 요구에서 제거한 항목이다. 상세 코드는 `scripts/ksi_lib/`, 명령 진입점은 `scripts/ksi.py`, 회귀 검사는 `tests/`에 있다.

v0.6.1은 `on_demand` 수동 모드와 `signal web-plan`/`signal batch-import`를 추가하고 새 heartbeat 실행을 거부한다. API 키와 예약 자동화 없이 공개 웹 원문을 조사·접수하고 후보를 재평가한다. `blue-ocean bootstrap`은 실험 결과 0건에서도 조사와 실행 준비를 계속하지만 가짜 고객·매출·전환율을 만들거나 building 이후 게이트를 우회하지 않는다.
